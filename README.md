# Pose Maker V18 Universal

Editor universal de pose, rig, animação e exportação 2D/JSON.

## V18
- Timeline Pro: duração, FPS, velocidade, duplicar/mover/excluir keyframes
- Biblioteca local de poses, expressões e animações
- Retargeting baseado em slots de rig universais
- Presets faciais por morph targets
- Eventos de animação (FIRE, FOOTSTEP, HIT, SFX/VFX etc.)
- Acessórios/armas por sockets
- Scene / Group Pose com avatares GLB adicionais
- Materiais, pele/cabelo e assets
- Projeto .gpose V18 e exportação JSON universal
- Sprite Pack 4/8 direções com PNG e sprite sheet
- Undo/Redo e Autosave local

> Alguns recursos dependem do rig/morphs existentes no GLB importado. Retargeting é baseado no mapeamento humano universal e pode exigir correção manual para rigs fora do padrão.

## V19 Responsive / Touch
- Desktop: painel esquerdo + viewport + inspector + timeline.
- Tablet: inspector vira painel lateral acionável.
- Android/iOS: viewport ocupa o centro; ☰ abre ferramentas e ⚙ abre inspector.
- Gestos: 1 dedo gira a câmera; 2 dedos fazem zoom/pan; sliders e timeline têm alvos maiores para toque.
- Usa `100dvh` e safe viewport para navegadores móveis.
- Suporta orientação retrato e paisagem.
